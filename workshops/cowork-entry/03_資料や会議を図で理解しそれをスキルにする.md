# 資料や会議を“図”で理解し、それをスキルにする

## プロンプト1: 会議のエグゼクティブサマリー作成

```
直近の会議で議事録があるものを検索して、
私向けに関連がありそうな観点で
エグゼクティブサマリーを作ってください。
```

## プロンプト2: 論点・結果・発言者・担当者の図解

```
さらに続けて、理解を助けるため、
論点と結果、その発言者、担当者を
図で理解できるようにHTML で1枚にまとめてください。
```

## プロンプト3: スキル化とスキル名の提案

```
ここまでの作り方をスキルとして保存してください。
そのスキルの名前は私にあったものを5個提案してください。
```

## プロンプト4: クイズアプリの作成

```
インプットした内容をもとにして、
ブラウザ単体で動作するクイズアプリを作成する。
```

## 使い方

1. 直近の会議の議事録を検索し、自分に関連するエグゼクティブサマリーを作成します。
2. 論点・結果・発言者・担当者の関係をHTML1枚の図として可視化します。
3. ここまでの一連の作業をスキルとして保存し、自分に合ったスキル名を5個提案してもらいます。
4. 最後に、学んだ内容をもとにブラウザ単体で動くクイズアプリを作成し、理解度を確認します。
