# 「わからない」を自力で解く

## プロンプト1: 社内用語の解説

```
社内でよく使われている略語や用語で、
私がまだ知らなさそうなものを10個、
意味とあわせて教えて。
```

## プロンプト2: 学習用の落ちゲー作成

```
これを学ぶことができる落ちゲーのゲームアプリを、
ブラウザで完全に動作する形式で作成して。
```

## プロンプト3: 最近の仕事

```
私が最近取り組んでいることについて、
社内の資料やメール、チャットなどから包括的に調べて、
わかりやすく説明して。
```

## プロンプト4: 図解イラストの生成

```
これをわかりやすく適切に挿絵を入れつつ図解した
イラスト画像を横向きレイアウトで生成して。
```

## プロンプト: 会議の予定

```
今日と明日の会議について
特に私が取り組むべき内容について調査し一覧にする
```

```
さらに必要な準備を提案し、私に質問を行います。
その回答内容に基づいて私に必要な支援を行います。
```


## 使い方

1. まずは社内用語を10個教えてもらい、自分の理解度を確認します。
2. その用語を学べる落ちゲーゲームをブラウザで作成してもらい、遊びながら覚えます。
3. 自分の最近の業務内容を調査してもらい、業務理解を深めます。
4. 調査結果をもとに、横向きレイアウトの図解イラストを生成してもらい、資料としてまとめます。
5. 直近の会議の準備を手伝ってもらいます。
