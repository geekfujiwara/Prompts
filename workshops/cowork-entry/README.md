# Cowork 体験ワークショップ

Cowork を体験するワークショップで使用したプロンプト集です。参加者が自分の業務に合わせてスキルを見つけたり、社内の「わからない」を自力で解決したり、資料や会議の内容を図解してスキル化する流れを体験できます。
