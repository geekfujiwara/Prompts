# 大阪名物キャッチゲーム

大阪の名物（たこ焼き、お好み焼き、串カツなど）を題材にした、上から落ちてくるアイテムをキャッチするブラウザゲームを作るためのプロンプトです。

より本格的な完全再現版（ニックネーム登録、スコア保存、ランキング、Azure Blob へのデプロイまで含む v9 相当）の
作成方法・遊び方・仕様は [HOW_TO_PLAY_AND_BUILD.md](./HOW_TO_PLAY_AND_BUILD.md) を参照してください。
公開デモ: https://stosakagame12414.z11.web.core.windows.net/

## プロンプト

```
大阪名物(たこ焼き、お好み焼き、串カツ、551の豚まんなど)が画面上部からランダムに降ってくる、
キャッチゲームをブラウザで完全に動作する形式(HTML/CSS/JavaScriptを1ファイルにまとめる)で作成してください。

- プレイヤーはキーボードの左右キー(または画面のボタン)でカゴを操作し、落ちてくる名物をキャッチする
- 名物ごとに得点を変える(例: たこ焼き10点、串カツ20点、豚まん30点)
- 大阪名物ではないもの(ハズレ)も混ぜて、キャッチすると減点になるようにする
- 制限時間(60秒程度)を設け、時間内の合計得点を表示する
- ゲームオーバー時にはリトライできるボタンを表示する
```

## 使い方

1. 上記プロンプトを Cowork に入力し、単一のHTMLファイルとしてゲームを生成してもらいます。
2. 生成されたHTMLファイルをブラウザで開いて動作を確認します。
3. ワークショップの参加者同士でスコアを競い合いながら、生成AIによるゲーム開発を体験します。
